# Historyczne skrypty

Skrypty `fix_*.cjs` i `patch_*.cjs` zostały użyte jednorazowo podczas
wczesnego rozwoju projektu. Pozostają tu wyłącznie jako zapis migracji;
nie są częścią aplikacji ani procesu wdrożenia.

Skrypty `step*.cjs`, `update_task*.cjs` i `download_font.cjs` leżały wcześniej
w katalogu głównym - to również jednorazowe migracje (zmiana nazwy na KartoLab,
pobranie starej czcionki Elementarz). Archiwum `elementarz.zip` ze starą
czcionką usunięto; aplikacja używa `public/fonts/Elementarz2.ttf`.
